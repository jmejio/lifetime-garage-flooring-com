# Prompt to start Working on the issues. Open the issue to work on and use this prompt:

FIRST read `@issues/prd.md` to understand the context of the open issues. Then read the file which is selected/opened which is the issue file but Do not read all other files under `/issues` folder (not subfolders) since these are open issues that will be handled at a later time. Alternatively, just start working on the issue at hand and ask me any questions if you have any.

Plan the steps necessary to complete the requirements of the issue at hand and ask me any questions if you have any.

Use a todo list that addresses the acceptance criteria.

Implement the code necessary to complete the issue. When the todo list is complete, move the issue file to `issues/done/`.

If the task is not complete, add a note to the issue file with what was done.
